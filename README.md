🔗 **Acesse em produção:** [https://thays-portfolio-six.vercel.app](https://thays-portfolio-six.vercel.app)

---

## Principais Funcionalidades & Destaques Técnicos

- **Arquitetura Moderna com Next.js App Router:** Construído sobre `src/app/` com tipagem estática em TypeScript e estilização responsiva via Tailwind CSS v4.
- **Vitrine de Projetos com Métricas Reais:** Destaque estruturado para projetos de Engenharia de Dados, Visão Computacional, Business Intelligence (Star Schema / SQL / Power BI) e Machine Learning, integrando repositórios do **GitHub** e **GitLab**.
- **UX & Acessibilidade:** Navegação fluida por âncoras, botão de cópia rápida de e-mail com feedback visual (`navigator.clipboard`), atalho direto para composição no Gmail e ícones vetoriais via `lucide-react`.

## Projetos Apresentados no Portfólio

1. **[Screentime vs. Education (GitLab)](https://gitlab.com/Landoftha/screentime_vs_Education):** Pipeline em chunks em Python/Pandas processando **12M+ registros** de 4 bases públicas federais (SAEB, Censo Escolar, PeNSE e TIC Kids Online), demonstrando o Paradoxo de Simpson controlado por INSE ($r = 0,875$) e ponto de inflexão em ~2,5h/dia via XGBoost + SHAP.
2. **[Sigma Body Analytics](https://github.com/Landoftha/sigma-body-analytics):** Pipeline multimodal em Python integrando **Google Fit REST API (OAuth2)** e **Gemini 2.5 Flash Vision OCR** para extração de dados de saúde e visualização no Looker Studio.
3. **[Grão Nobre Analytics](https://github.com/Landoftha/grao-nobre-analytics):** Plataforma de Business Intelligence com modelagem dimensional **Star Schema** (4 tabelas fato e 6 dimensões), gerador de dados sintéticos, consultas SQL analíticas e medidas DAX para Power BI.
4. **[Detecção de Fraude Bancária](https://github.com/Landoftha/EDA-Analise-de-Fraude):** Análise estatística descritiva/inferencial e benchmark de modelos de Machine Learning em bases financeiras desbalanceadas (suite NeurIPS 2022).
5. **[Egg Outlier Detection](https://github.com/Landoftha/egg_outlier_detection):** Visão computacional com OpenCV, Isolation Forest, Autoencoder (**97,45% ROC-AUC**) e MLP (**92,71% de acurácia** em validação cruzada 5-fold).

## Como Executar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/Landoftha/my-portfolio.git
cd my-portfolio

# 2. Instale as dependências
npm install

# 3. Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador para visualizar a aplicação.
