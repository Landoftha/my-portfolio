# 🌟 Thays Yohana Costa — Data Science & Analytics Portfolio

Portfólio profissional de Ciência de Dados, Engenharia de Dados e Inteligência Artificial Multimodal desenvolvido com **Next.js**, **Tailwind CSS** e **TypeScript**.

---

## 🚀 Projetos em Destaque

1. **[Screentime vs. Education](https://gitlab.com/Landoftha/screentime_vs_Education) (GitLab):** Big Data (12M+ microdados federais do SAEB, Censo Escolar, PeNSE e TIC Kids), superação do Paradoxo de Simpson, modelagem de painel e XGBoost com interpretabilidade SHAP.
2. **[Sigma Body Analytics](https://github.com/Landoftha/sigma-body-analytics) (GitHub):** Pipeline automatizado de saúde com Google Fit API, Visão Computacional multimodal (Gemini 2.5 Flash para OCR de treinos) e BI no Looker Studio.
3. **[Grão Nobre Analytics](https://github.com/Landoftha/grao-nobre-analytics) (GitHub):** Plataforma omnichannel de analytics para cafeterias especiais em Curitiba, SP e Florianópolis, modelagem dimensional Star Schema e métricas de varejo.
4. **[Detecção de Fraudes Bancárias](https://github.com/Landoftha/EDA-Analise-de-Fraude) (GitHub):** Análise estatística inferencial e benchmark de algoritmos em dados desbalanceados com a suite NeurIPS 2022.

---

## 🛠️ Stack Tecnológica

- **Framework Web:** Next.js 16 (App Router), React 19, Tailwind CSS v4, TypeScript, Lucide Icons.
- **Data Science & ML:** Python, Pandas, NumPy, Scikit-Learn, XGBoost, SHAP (XAI), Econometria / Modelos de Painel.
- **IA & Multimodal:** Google Gemini 2.5 Flash (Vision AI OCR), Engenharia de Prompts.
- **Deploy & Infra:** Vercel, Git, GitHub, GitLab, Docker.

---

## 💻 Como Rodar Localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.
